# Pharaoh: A New Era — Русский перевод / Russian Localization

Данный проект представляет собой **неофициальный русификатор** для игры **Pharaoh: A New Era** — современного ремейка классического градостроительного симулятора от Impressions Games.

### Описание

Русификатор включает в себя полный перевод интерфейса, диалогов, кампаний, подсказок и игровых текстов на русский язык.  
Дополнительно переведены моды из популярного пакета модификаций.

Руссификатор работает через мод **PANECustomLocalization**, который входит в состав пакетаа модов **Bug Fixes and Enhancements Package** :  
  https://www.nexusmods.com/pharaohanewera/mods/16

За основу локализатора взяты наработки сообщества, и особенно — переводы от **winterheart**, доступные в репозитории:  
  https://github.com/winterheart/pharaoh-l10n. а также тексты, созданные с использованием **AI** (машинный перевод с последующей доработкой).

### Состав

- Полный (надеюсь) перевод всех внутриигровых строк.
- Локализация меню, кампаний, миссий и событий.
- Адаптация названий зданий, ресурсов и профессий.
- Субтитры для видео из оригиналььной игры
- Перевод модов из пакета Bug Fixes and Enhancements Package.

### Установка

#### 1. Установите необходимый мод
Перевод работает через мод **PANECustomLocalization**, который входит в состав пакета:  **Bug Fixes and Enhancements Package** https://www.nexusmods.com/pharaohanewera/mods/16
- Установите **Bug Fixes and Enhancements Package** целиком, либо
- Установите отдельно модуль **PANECustomLocalization** из состава пакета.

#### 2. Установите файлы перевода
Распакуйте содержимое архива локализатора в папку с игрой.  
Файлы *-ru.csv должны оказаться в каталоге: ```ModResources/Localizations```

#### 3. (Опционально) Голосовое озвучивание
Если у вас есть оригинальная русифицированная игра **Pharaoh** (классическая версия), вы можете использовать её звуковые ресурсы для голосового сопровождения в ремейке.

Для этого скопируйте содержимое папки:
```<папка оригинальной игры>\Audio\voice```
в папку ремейка:
```<папка ремейка>\ModResources\Localizations\ru\voice```

**Важно:** Тексты перевода в данном русификаторе и тексты, использованные в популярной русскоязычной версии классической игры, **не совпадают дословно**. Перевод выполнен заново на основе оригинальных английских текстов, поэтому возможны расхождения в формулировках. Голосовое озвучивание будет воспроизводиться в соответствии с аудиофайлами из оригинальной игры, даже если текст на экране отличается от того, что произносится голосом.

#### 4. Активация в игре
Запустите игру, откройте **настройки** и выберите язык **"Русский"**.


### Часто задаваемые вопросы

**Вопрос:** Нужно ли устанавливать все моды из пакета?  
**Ответ:** Нет, достаточно только **PANECustomLocalization**, но весь пакет не помешает — он содержит множество полезных исправлений.

**Вопрос:** Где взять оригинальные голоса?  
**Ответ:** Они есть только в классической версии игры Pharaoh (1999). Если у вас её нет — будет использовано озвучивание из игры на анлийском языке.

**Вопрос:** Поддерживает ли русификатор другие моды?  
**Ответ:** Напрямую — только моды из указанного пакета. Для других модов потребуется дополнительные строки.

**Вопрос:** Почему текст на экране не совпадает с голосом из классической игры?  
**Ответ:** Как указано выше, перевод был выполнен заново и не является дословной копией перевода из классической версии. Это нормально — голосовые файлы остались те же, а за основу перевода были взяты тесты из ремейка.

## English

This project is an **unofficial Russian localization mod** for **Pharaoh: A New Era** — the modern remake of the classic city-building game by Impressions Games.

### Description

The mod provides a full Russian translation of the interface, dialogues, campaigns, tooltips, and all in-game texts.  
Additionally, mods from the popular mod pack are also translated.

The translation is based on сommunity contributions, especially the work of **winterheart**, available at: https://github.com/winterheart/pharaoh-l10n, additionally texts generated and refined using **AI**.

### Contents

- Full translation of all in-game strings.
- Localized menus, campaigns, missions, and events.
- Adapted names for buildings, resources, and professions.
- Translated mods from the Bug Fixes and Enhancements Package.

### Installation

#### 1. Install the required mod
The translation works through the **PANECustomLocalization** mod, which is included in the package: **PANECustomLocalization** https://www.nexusmods.com/pharaohanewera/mods/16
- Install the full **Bug Fixes and Enhancements Package**, or
- Install the **PANECustomLocalization** module separately from the package.

#### 2. Install translation files
Extract the localization archive into your game folder.  
The *-ru.csv files must be placed in the following directory:
*ModResources/Localizations*

#### 3. (Optional) Voice-over audio
If you have the original Russian-localized version of **Pharaoh** (the classic 1999 game), you can use its audio resources for voice-over support in the remake.

Copy the contents of the folder:
```<original game folder>\Audio\voice```
to the remake's folder:
```<remake folder>\ModResources\Localizations\ru\voice```

**Important:** The translated texts in this localization mod and the texts used in the popular Russian version of the classic game **do not match verbatim**. The translation has been redone from scratch based on the original English texts, so there may be discrepancies in wording. Voice-over audio will play according to the audio files from the original game, even if the on-screen text differs from what is being spoken.

#### 4. Activate in-game
Launch the game, open **Settings**, and select **"Русский"** (Russian) as your language.



### FAQ

**Q:** Do I need to install all mods from the package?  
**A:** No, only **PANECustomLocalization** is required. However, installing the full package is recommended — it includes many useful bug fixes and enhancements.

**Q:** Where can I get the original voice-overs?  
**A:** They are only available in the classic version of Pharaoh (1999). If you don't have it, the game will still be fully playable without voice-over.

**Q:** Why doesn't the on-screen text match the voice from the original game?  
**A:** As mentioned above, the translation was redone and is not a verbatim copy of the translation from the classic version. This is normal — the voice files remain the same, while the texts have been updated for greater accuracy and better alignment with the remake.
